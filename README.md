## Genomic Sequence Search Engine

## Project Overview

This project aims to develop a genomic sequence search engine for searching and identifying matching patterns in DNA sequences.

## Objectives

- Implement efficient string matching algorithms.
- Search for patterns in genomic sequences.
- Analyze and compare algorithm performance.
- Provide accurate search results.

- Python
